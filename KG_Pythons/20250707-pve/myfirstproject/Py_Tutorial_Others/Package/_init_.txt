1. 일반 정보
* __init__.py 파일은 패키지를 초기화하고, 초기화 코드와 하위 모듈을 포함할 수 있음.
* 패키지를 만들 때 디렉토리 구조와 파일을 적절히 배치하여 효율적인 모듈 관리를 할 수 있음.
* Python 3.3 이후로는 __init__.py 파일이 없어도 해당 디렉토리가 패키지로 인식됨.
  - 하지만, __init__.py 파일이 없으면 패키지를 초기화하는 코드나 하위 모듈 및 하위 패키지를 자동으로 포함하는 기능을 사용할 수 없음. 
  - 더불어, __init__.py를 다루지 못하면 외부 패키지를 가져다 쓰지 못할 수 있음.

2. 패키지 관리 학습 목표
  - __init__.py 파일이 없는 패키지/서브 패키지를 만들어본다.
  - __init__.py 파일을 가진 패키지/서브 패키지를 만들어본다.
  - __init__.py 파일을 가진 패키지/서브 패키지를 만들어본다. + Log, Config 추가해본다.
