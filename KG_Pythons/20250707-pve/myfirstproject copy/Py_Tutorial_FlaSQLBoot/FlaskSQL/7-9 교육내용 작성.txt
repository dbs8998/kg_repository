# 1️⃣ Flask란?
# Flask는 Python으로 만든 “가벼운 웹 프레임워크”입니다.
# 마이크로 프레임워크라고 불려요.

# "마이크로”는 기능이 적다는 뜻이 아니라 필수 구성만 작게 제공하고 나머지는 자유롭게 선택해서 붙여 쓴다는 의미.
# 웹 서버를 쉽게 만들 수 있게 도와줍니다.


✅ 1️⃣ NoSQL DB란?
NoSQL = “Not Only SQL”
전통적인 **관계형 데이터베이스(RDBMS)**와 다른 방식으로 데이터를 저장하고 관리하는 데이터베이스 유형입니다.

SQL을 안 쓴다는 의미가 아니라 꼭 테이블/스키마/조인 중심이 아닌 다양한 모델을 지원한다는 의미.

대량의 데이터를 유연하게 저장하고, 수평적 확장을 쉽게 지원.

✅ 2️⃣ NoSQL의 핵심 특징
스키마 유연성

고정된 테이블 구조가 필요 없음

각 레코드가 다른 구조 가능

수평적 확장성

서버 여러 대로 쉽게 확장 가능 (샤딩)

고가용성

분산 아키텍처로 장애 대응

다양한 데이터 모델

요구에 맞는 모델 선택 가능




# ✅ 1️⃣ 도큐먼트 DB란?
# 도큐먼트(Document) 데이터베이스는 데이터를 문서(Document) 단위로 저장하고 관리하는 NoSQL 데이터베이스의 한 종류입니다.

# 문서(Document) = 데이터의 구조화된 단위

# 보통 JSON, BSON, XML 같은 형식으로 저장

# 각 문서가 자기완결적인 구조를 가짐 → 스키마가 유연함


✔️ ③ 컬럼 패밀리(Column-Family) DB
행(Row)과 컬럼(Column) 개념은 유지

하지만 컬럼이 유연하게 그룹화 → 빅데이터 분석에 유리

✅ 예시: Cassandra, HBase

예
RowKey: user123
  → personal:name = "kim"
  → personal:age = 30
✔️ ④ 그래프(Graph) DB


노드(Node)와 엣지(Edge)로 관계를 표현

복잡한 관계형 쿼리 최적화

✅ 예시: Neo4j, Amazon Neptune

예

(kim)-[FRIEND]->(lee)
